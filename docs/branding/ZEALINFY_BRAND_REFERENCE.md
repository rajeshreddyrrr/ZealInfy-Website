# ZealInfy Brand Reference

## Approved wordmark

The current approved ZealInfy wordmark is:

- Text: **ZealInfy**
- Capitalization: **ZealInfy**
- Treatment: single-color blue wordmark
- Primary blue: **#1677D2**
- Style: clean, modern, corporate sans-serif
- No icon or separate Z mark
- No surrounding box, border, or badge
- No gradient in the primary wordmark
- Keep clear space around the wordmark

## Approved repository assets

- `/public/logo.svg` — primary ZealInfy wordmark used by the website
- `/public/favicon.svg` — browser/search favicon using the ZealInfy wordmark

## Brand direction

Use the same blue wordmark consistently across the website, browser identity, social previews, and future brand materials unless a new brand direction is explicitly approved.

The website's broader visual system can continue using the dark navy, blue, and cyan technology aesthetic, but the core ZealInfy wordmark remains a simple solid-blue wordmark.

## Important

Do not replace the wordmark with a Z-only icon or unrelated symbol without explicit approval.
